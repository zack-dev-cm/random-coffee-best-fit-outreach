# Workflow

## Operator Loop

1. Collect opt-in or intentionally public participant data.
2. Normalize it into the CSV schema.
3. Run the matcher report.
4. Review top pairs for utility, risks, and consent.
5. Generate an intro packet for one selected pair.
6. Ask for approval before any LinkedIn or Discord outreach.
7. Use OpenClaw or Computer Use only for reviewed browser or GUI work.
8. Log outcome and update participant notes.

## Release Loop

1. Keep examples fictional.
2. Run tests and CLI smoke.
3. Run the Codex harness audit.
4. Review README, `SKILL.md`, and docs for leak or platform-boundary drift.

# Public Boundary

This repo is intended for public release. Keep these boundaries intact:

- Do not commit real participant exports.
- Do not commit LinkedIn or Discord cookies, browser profiles, screenshots with private messages, or raw profile dumps.
- Do not add automated LinkedIn send logic, Discord selfbot behavior, auto-DMs, auto-joins, or invite spam.
- Do not add code that bypasses login, captcha, rate limits, user privacy settings, or platform controls.
- Keep public examples fictional and reusable.
- Keep generated outreach opt-in based and reversible. A recipient must be able to decline without pressure.

The public product is the repeatable matching and review process. The operator's private network and browser state stay outside the repo.

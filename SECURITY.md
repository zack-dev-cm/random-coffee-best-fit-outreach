# Security Policy

## Supported Versions

The `main` branch is the supported development line until the first stable release.

## Reporting a Vulnerability

Please open a private security advisory or contact the maintainer through the repository owner profile. Do not include secrets, cookies, private LinkedIn or Discord data, or participant personal data in public issues.

## Scope

Security reports are in scope when they affect:

- unsafe handling of participant data
- accidental disclosure in generated packets or logs
- behavior that could enable hidden scraping, account abuse, or unapproved live outreach
- dependency or packaging issues in the Python CLI or skill bundle
